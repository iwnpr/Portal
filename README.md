# Portal

Простое серверное Blazor-приложение с формой входа и авторизацией через LDAP GitLab.

## Возможности

- Форма входа с проверкой учётных данных в LDAP GitLab.
- Сохранение сессии в защищённом хранилище браузера.
- Авторизация и разграничение доступа по ролям, автоматически загружаемым из групп LDAP.
- Демонстрационная страница администратора, доступная только роли `Administrator`.

## Настройка

1. Откройте файл `src/PortalApp/appsettings.json` и задайте параметры подключения к вашему LDAP GitLab:
   - `ServerUrl` и `Port` — адрес и порт LDAP сервера GitLab.
   - `UseSsl` — `true`, если используется LDAPS.
   - `BaseDn`, `UserDnPattern` и `GroupSearchBase` — базовые DN для поиска пользователей и групп.
   - `GroupRoleMappings` — сопоставление LDAP-групп ролям приложения.

2. Соберите и запустите проект:

   ```bash
   dotnet restore
   dotnet run --project src/PortalApp/PortalApp.csproj
   ```

   Приложение будет доступно по адресу `https://localhost:5001` (по умолчанию).

## Структура проекта

- `src/PortalApp/` — Blazor Server приложение.
  - `Pages/Login.razor` — форма входа.
  - `Services/` — службы для аутентификации и управления состоянием пользователя.
  - `wwwroot/css/site.css` — простое оформление.

## Примечания

- Для успешной авторизации необходимо, чтобы у пользователя была учётная запись в LDAP GitLab, и он состоял в группах, перечисленных в сопоставлении ролей.
- Для демонстрации предусмотрена страница `/admin`, доступная только роли `Administrator`.
